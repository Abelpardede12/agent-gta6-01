Sunset Keys is an original open-world crime mini-game that runs entirely in the browser: drive and walk around the fictional sun-soaked city of Sunset Keys, steal cars, dodge traffic, outrun the police as your wanted level rises, and run timed missions for cash. Everything — the city, characters, vehicles, story, art and sound — is original.

Controls: WASD or arrow keys to move/drive, E to enter or exit a car, Space to brake, mouse to look around. Touch controls on mobile.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play. No build step, no network requests — the game is static files under `game/`.
